Запуск
1. Распакуйте архив.
2. Откройте FloydWarshall.csproj в Visual Studio с поддержкой .NET 10.
3. Нажмите Ctrl+F5.
Или выполните в папке проекта: dotnet run

Меню
1 — найти путь и показать матрицу всех кратчайших расстояний.
2 — разорвать или восстановить ребро по номеру с рисунка.
0 — выход.
Вершины вводятся латинскими буквами A–E.
Рисунок graph.svg показывает исходный граф. Текущее состояние рёбер видно в консоли.

Пример
Из A в E: A -> B -> C -> D -> E, вес 7.
Отключите ребро №3 (B -> C): путь A -> C -> D -> E, вес 10.
Отключите оба ребра №6 и №7: пути в E больше нет.
Повторный выбор номера восстанавливает ребро.

Что рассказать учителю
Я написал программу на C#, которая реализует алгоритм Флойда — Уоршелла.
Он находит кратчайшие пути между всеми парами вершин.
Сначала создаётся матрица: на диагонали нули, для рёбер записаны их веса,
а отсутствие пути обозначается бесконечностью.
Затем три вложенных цикла перебирают промежуточную вершину k,
начало i и конец j. Если путь через k короче, расстояние обновляется:
d[i,j] = min(d[i,j], d[i,k] + d[k,j]).
Для восстановления маршрута хранится следующая вершина пути.
В меню можно разрывать и возвращать рёбра; при поиске матрица рассчитывается заново.
Алгоритм допускает отрицательные рёбра. Отрицательное число на диагонали
после расчёта указывает на отрицательный цикл; программа останавливает вывод результатов.
В отличие от Беллмана — Форда, здесь сразу вычисляются расстояния для всех пар вершин.
Время работы: O(V^3). Дополнительная память: O(V^2).
